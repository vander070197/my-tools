link-validator

Paste a list of URLs and check which ones are accessible, 404 Not Found, or returning another HTTP error.

note — browsers can't read a cross-origin status code directly (CORS). This tool tries a direct request first, then falls back through independent public proxies (with a retry) to read the real response. If every method agrees on a 403/429/503, that's flagged separately since those codes usually mean a proxy got blocked, not that the link is dead — see the note above the table when it happens. A row is only marked Unable to verify if nothing responds at all — hover the badge to see why, or hit retry / Retry Failed.
